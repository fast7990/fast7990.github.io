# 工具类网站 - 整体设计文档

---

## 一、项目概述

### 1.1 项目定位

一个纯前端的在线工具集合网站，面向开发者和普通用户，提供 JSON 格式化、图片转 Base64、二维码生成等常用工具。所有数据处理均在浏览器端完成，无需后端服务，保障用户隐私。

### 1.2 核心价值

- 开箱即用，无需安装任何软件
- 数据不上传服务器，隐私安全
- 响应式设计，支持 PC / 平板 / 手机多端访问
- 炫酷的视觉效果，提升使用体验

---

## 二、技术选型

| 类别 | 技术方案 | 说明 |
|------|---------|------|
| 前端框架 | Vue 3 (Composition API) | 轻量、高性能 |
| 构建工具 | Vite | 极速冷启动和热更新 |
| 路由管理 | Vue Router 4 | SPA 单页应用路由 |
| 样式方案 | 原生 CSS + CSS Variables | 深色主题 + 动态变量 |
| 粒子效果 | tsparticles (`@tsparticles/vue3`) | 高性能粒子动画引擎 |
| 二维码 | `qrcode` | 二维码生成与导出 |
| 部署方式 | GitHub Pages | 静态站点托管 |

## 三、功能模块详细设计

### 3.1 JSON 格式化

| 功能点 | 描述 |
|--------|------|
| 格式化（美化） | 将压缩的 JSON 字符串格式化为带缩进的可读格式 |
| 压缩 | 将格式化的 JSON 压缩为单行字符串 |
| 语法校验 | 实时检测 JSON 语法错误，提示错误位置和原因 |
| 树形展示 | 以可折叠的树形结构展示 JSON 数据 |
| 转义/反转义 | 支持 JSON 字符串的转义和反转义操作 |

**交互设计：**
- 左侧输入区，右侧输出区，双栏布局
- 顶部工具栏提供操作按钮（格式化、压缩、复制、清空）
- 输入时实时校验，错误时高亮提示

### 3.2 图片转 Base64

| 功能点 | 描述 |
|--------|------|
| 图片上传 | 支持点击上传和拖拽上传 |
| 格式支持 | PNG、JPG、GIF、WebP、SVG、ICO 等 |
| 实时预览 | 上传后即时显示原图预览 |
| 输出格式 | 可选 Data URL（`data:image/png;base64,...`）或纯 Base64 |
| 一键复制 | 快速复制生成的 Base64 字符串 |
| 文件信息 | 显示文件大小、尺寸、格式等信息 |

**交互设计：**
- 大面积拖拽区域，支持拖放和点击选择
- 上传后显示图片预览 + Base64 输出文本框
- 提供复制按钮，复制成功后给出视觉反馈

### 3.3 二维码生成

| 功能点 | 描述 |
|--------|------|
| 内容输入 | 支持文本、URL、电话号码等 |
| 尺寸自定义 | 可选 128px ~ 1024px |
| 颜色自定义 | 前景色、背景色可自由选取 |
| Logo 嵌入 | 支持在二维码中心嵌入 Logo 图片 |
| 容错级别 | 可选 L / M / Q / H 四个容错等级 |
| 下载导出 | 支持下载为 PNG 图片 |

**交互设计：**
- 左侧配置面板，右侧实时预览
- 修改参数后二维码实时更新
- 提供下载按钮

### 3.4 后续扩展工具

| 工具 | 描述 | 优先级 |
|------|------|--------|
| 时间戳转换 | Unix 时间戳与日期互转 | 高 |
| URL 编解码 | URL 编码/解码 | 高 |
| MD5/SHA 哈希 | 文本和文件的哈希计算 | 中 |
| 颜色格式转换 | HEX / RGB / HSL 互转 | 中 |
| 正则表达式测试 | 正则匹配和替换测试 | 中 |
| 文本差异对比 | 两段文本的 diff 对比 | 低 |
| UUID 生成器 | 批量生成 UUID | 低 |

## 五、页面视觉设计

### 5.1 整体视觉风格

```
┌─────────────────────────────────────────────────────┐
│                    深色背景 (#0a0a1a)                 │
│   ·  ·    ·        ·    ·  ·    粒子层               │
│      ·    ·  ·  ·     ·      ·    (tsparticles)     │
│   ·    ·       ·    ·   ·  ·    ·                    │
│  ┌───────────────────────────────────────────────┐   │
│  │  ╔═══════════════════════════════════════╗    │   │
│  │  ║     毛玻璃容器 (backdrop-blur)         ║    │   │
│  │  ║                                       ║    │   │
│  │  ║   霓虹渐变标题 (蓝紫 → 青绿)           ║    │   │
│  │  ║   发光按钮 (box-shadow glow)           ║    │   │
│  │  ╚═══════════════════════════════════════╝    │   │
│  └───────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────┘
```

- **主色调：** 深色背景 `#0a0a1a`，搭配霓虹渐变高亮（蓝紫 `#7c3aed` → 青绿 `#06b6d4`）
- **毛玻璃效果：** `backdrop-filter: blur(12px)` + 半透明背景 `rgba(255,255,255,0.05)`
- **发光效果：** 按钮和边框使用 `box-shadow` 实现辉光
- **渐变文字：** 标题使用 `background-clip: text` 实现渐变效果

### 5.2 粒子背景设计

- 使用 `tsparticles` 实现全屏粒子动画
- 粒子特性：
  - 数量：桌面端 80-100 个，移动端 30-40 个
  - 颜色：蓝紫色系，透明度 0.3-0.7
  - 大小：2-5px 随机
  - 移动速度：缓慢随机方向
  - 连线：距离 < 150px 的粒子间绘制半透明连线
  - 鼠标交互：鼠标附近粒子产生排斥/吸引效果
- 性能降级策略：
  - 移动端自动减少粒子数量
  - 低性能设备关闭连线效果
  - 通过 `requestAnimationFrame` 控制帧率

## 六、响应式适配方案

### 6.1 断点定义

| 断点名称 | 范围 | 设备类型 |
|---------|------|---------|
| `mobile` | < 768px | 手机 |
| `tablet` | 768px ~ 1023px | 平板 |
| `desktop` | >= 1024px | 桌面 |

### 6.2 各断点布局策略

| 元素 | 桌面端 | 平板端 | 移动端 |
|------|--------|--------|--------|
| 工具卡片网格 | 3~4 列 | 2 列 | 1 列 |
| 工具页面双栏 | 左右并排 | 左右并排 | 上下堆叠 |
| 导航栏 | 完整菜单 | 完整菜单 | 汉堡菜单 |
| 粒子数量 | 80-100 | 50-70 | 30-40 |
| 粒子连线 | 开启 | 开启 | 关闭 |
| 页面内边距 | 48px | 24px | 16px |

### 6.3 移动端特殊处理

- 导航栏折叠为汉堡菜单，点击展开侧边抽屉
- 工具页面输入/输出区域改为上下堆叠
- 粒子效果自动降级，减少数量并关闭连线
- 所有可点击元素最小尺寸 44x44px（Apple HIG 标准）
- 拖拽上传区域在移动端增加点击上传的明显提示

## 九、性能优化策略

| 策略 | 说明 |
|------|------|
| 路由懒加载 | 工具页面使用 `() => import(...)` 按需加载 |
| 粒子降级 | 根据设备性能自动调整粒子参数 |
| 防抖/节流 | 输入类操作使用 debounce，滚动/resize 使用 throttle |
| 大文件处理 | 图片转 Base64 使用 `FileReader`，大文件分块处理 |
| CSS 动画 | 优先使用 `transform` 和 `opacity`，触发 GPU 加速 |
